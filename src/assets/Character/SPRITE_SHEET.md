# Sprite Sheet Spec

Place the sprite sheet at:

- src/assets/Character/steven-sprite.png

Layout and order:

- 4 columns x 2 rows
- Frame size: 64x64 (or confirm a different size)
- Order (left to right, top to bottom):
  1) Idle 1
  2) Idle 2
  3) Run 1
  4) Run 2
  5) Run 3
  6) Run 4
  7) Jump up
  8) Fall/down
